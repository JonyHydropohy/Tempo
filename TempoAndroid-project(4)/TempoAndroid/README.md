# Tempo — Android project

Первая локальная версия личного планера на Java / Android SDK.

## Что уже реализовано
- тёмный интерфейс;
- создание событий с датой, временем, местом и примерным временем дороги;
- локальное сохранение расписания;
- настройка запаса и времени напоминания;
- локальное Android-уведомление перед событием;
- открытие Яндекс Карт для построения маршрута общественным транспортом;
- импорт событий из CSV/TXT и календарных ICS-файлов;
- импорт местоположений занятий из поля адреса в файле расписания;
- долгое нажатие на событие для удаления.

## Импорт расписания
На главном экране нажми «Импорт расписания МЭШ / CSV / ICS». Выбор файла работает через системный файловый picker Android.

CSV в UTF-8: одна строка на событие, поля `дата,название,время,адрес,дорога_в_минутах`, например:
`2026-10-12,Футбол,17:00,Спортивная улица 5,35`

Также читаются базовые события ICS (SUMMARY, DTSTART, LOCATION). Импорт повторяющихся правил календаря (RRULE) пока не разворачивается в отдельные даты. Прямой авторизованный доступ к МЭШ не реализован: если МЭШ не предоставляет экспорт в файл, понадобится поддерживаемый официальный способ интеграции или импорт через совместимый файл.

## Что пока не реализовано
- автоматическое получение расписания школы и тренировок;
- автоматический импорт расписаний;
- синхронизация с API транспорта и вычисление оптимального маршрута внутри Tempo;
- изменение существующего события и повторение по дням недели.

Сейчас Tempo передаёт маршрут Яндекс Картам. Расчёт маршрута и актуальные отправления выполняются самими Картами. Для интеграции с API Яндекса может понадобиться ключ и проверка доступности нужного API.

## Сборка APK
1. Установи Android Studio на компьютер: https://developer.android.com/studio
2. Открой папку `TempoAndroid` через **Open**.
3. Дождись синхронизации Gradle и установки Android SDK 35 (если предложит).
4. Для теста нажми Run и выбери Android-телефон с включённой отладкой по USB.
5. Для APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Файл обычно появится в `app/build/outputs/apk/debug/app-debug.apk`.

Требуется Android SDK и доступ к репозиториям Gradle. В этой среде Android SDK/Gradle не обнаружены, поэтому APK здесь не собран; исходный проект подготовлен для сборки в Android Studio.

## Автоматическая сборка APK на GitHub

В проект добавлен workflow `.github/workflows/build-apk.yml`. После загрузки проекта в GitHub Actions собирает debug APK автоматически при push в ветку `main`/`master`; также сборку можно запустить вручную через Actions → Build Tempo APK → Run workflow.

Чтобы скачать APK: откройте вкладку Actions, выберите успешный запуск `Build Tempo APK`, прокрутите страницу запуска до раздела Artifacts и скачайте `Tempo-debug-apk`. Внутри будет `app-debug.apk`. Это тестовая debug-сборка, не подписанный релиз для Google Play.
